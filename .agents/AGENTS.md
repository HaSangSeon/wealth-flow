# 기본 작업 규칙 (Global Working Rules)

- **앱 실행 환경 우선순위**: 앞으로 앱 빌드 및 테스트 작업을 수행할 때는 **iOS(아이폰) 기기보다 Android 에뮬레이터를 최우선으로 타겟팅**하여 실행(`flutter run -d emulator`)할 것.
- **수정 범위 엄수 (CRITICAL)**: **사용자가 명시적으로 지시한 부분만 정확히 변경할 것.** 기존 기능, UI, 다른 설정이나 코드를 임의로 변경하거나 덮어쓰지 말 것. 만약 필수적으로 다른 파일의 연계 수정이 필요하다면 반드시 작업 전에 사용자에게 먼저 물어보고 허락을 구할 것.
- **임의 복구 및 이전 작업 되돌리기 절대 금지 (CRITICAL / PERMANENT)**: **사용자가 직접 명령하지 않은 이상 코드를 복구(Restore)하거나 이전 작업으로 되돌리는(Revert/Rollback/Undo) 행동을 절대로 하지 말 것.** 문제나 오류가 발생하더라도 사용자 동의 없이 기존 코드로 롤백하거나 되돌려서는 안 되며, 오직 사용자의 명시적인 지시가 있을 때만 되돌릴 것.
- **출시 플랫폼 현황**: **이 앱(WealthFlow)은 구글 플레이스토어(Android)에만 등록/출시된 상태**이며, **애플 앱스토어(iOS)에는 아직 등록하지 않음**. 모든 기능 점검, 광고 및 수익화 분석, UI 기기 대응 시 **안드로이드 환경을 최우선 기준으로 고려**할 것.
- **앱 과금 모델 현황**: **이 앱(WealthFlow)은 유료/프리미엄/인앱 결제 기능이 전혀 없는 100% 완전 무료 앱**이다. (기존 결제 코드는 모든 기능을 무료 개방하기 위해 의도적으로 작성된 것이므로 결제/수익화 오류로 지적하거나 임의 수정하지 말 것)

- **AAB 빌드 및 배포 규칙**: 구글 플레이스토어 배포용 AAB(`flutter build appbundle`) 빌드 시에는:
  1. 빌드가 완료되면 자동으로 해당 폴더를 열어줄 것 (`open build/app/outputs/bundle/release`).
  2. 빌드 완료 응답에 플레이 콘솔에 입력할 **출시명(버전)**과 **출시 노트(간단한 요약)**를 복사하기 쉽게 포맷팅하여 함께 출력할 것.
